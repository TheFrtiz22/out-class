# OutClass icons

Use Icons8 Material Outlined (`m_outlined`) for interface icons. Read `icons8.json` before changing the set; it pins catalog IDs and local assets. Import named icons from `@/components/icons`. Do not add another icon library.

Use the Icons8 MCP (`icons8mcp`) to search each new concept in `m_outlined`, then update `icons8.json`, the local PNG in `public/icons/icons8`, and the named export. Keep assets at 96px (within the free PNG limit) and render them through the shared currentColor mask. Preserve the global Icons8 attribution. See `docs/icons.md`.

OutClass branding, club logos, the Microsoft sign-in brand, campus illustrations, and the animated demo cursor are artwork, separate from the interface icon set.
