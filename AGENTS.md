# OutClass icons

Use `@phosphor-icons/react` for all interface icons. Import named icons from `@/components/icons`; add semantic mappings there using individual `@phosphor-icons/react/dist/ssr/Name` imports so the same native SVGs work in Next.js Server and Client Components without a context provider. Do not add another icon library or use raster/remote interface icons.

Use Regular by default and Fill for selected navigation or saved states where appropriate. Preserve existing size, currentColor, spacing, accessible labels, focus behavior, and refs. Keep the package's MIT notice in `public/licenses/phosphor-icons-MIT.txt`. See `docs/icons.md`.

OutClass branding, club logos, the Microsoft sign-in brand, campus illustrations, and the animated demo cursor are artwork, separate from the interface icon set.
