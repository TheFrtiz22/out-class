# Floating navigation dock

The authenticated desktop navigation introduced in [PR #67](https://github.com/TheFrtiz22/out-class/pull/67) now uses automatic expansion, icon magnification, a shared moving highlight, and portaled group flyouts.

See [Premium expanding dock V2](expanding-dock-v2/README.md) for the baseline audit, architecture, keyboard controls, changed files, screenshots, and complete verification commands. Mobile retains its existing labeled drawer and bottom bar. Route callbacks, permission filtering, and leave guards remain in the shared shell.
