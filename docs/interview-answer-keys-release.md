## Implementation

A later imported bank question stores optional authenticated `bankQuestion.guidance` metadata in the existing JSON draft; the server validates the new reference against the current authorized bank and preserves it thereafter. Off-script questions have no reference. Historical drafts remain valid. Applicant projections and leadership closing projections do not include interview keys/private question notes.
- One persistent miscellaneous-notes textarea sits above right-panel question rows during both phases. Autosave retains its draft, and a serialized save waits for any pending request before capturing the latest submission. Finalization guards duplicate requests and retains failure/revision recovery. Phase changes merge into current state without overwriting edits made during a save.
- End interview first acknowledges the phase/draft save, then moves visible used questions into independent collapsed review rows. Untouched questions do not move; used questions remain distinguishable from personal completion. Already completed right-panel questions collapse in place. Question review/edits remain below miscellaneous notes, alongside closing work, until submission locks all fields.
