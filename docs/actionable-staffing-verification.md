# Actionable interviewer staffing checks

The Confirm interviewers step keeps a single concise issue area beside its confirmation controls. Availability changes display “Availability has changed. Recheck assignments before confirming.” with the existing server revalidation action exposed as “Recheck availability.” Both availability and staffing refresh events invalidate the UI immediately without replacing saved/local assignments. The warning remains latched through failures and edits until a successful current recheck; a change arriving during a recheck cannot produce a false success. Checking has a disabled pending control and duplicate-operation guard. Failures retain assignments and diagnostics with the same retry action.

Revalidation still calls the existing revision-checked protected action, reloads current validation and respects the canonical president-override rules. Invalid or changed sessions require repair rather than bypassing checks. The confirmation and final publication actions still independently verify current data, fingerprints, access, conflicts, duration, buffers and booking safety. No backend action, permission, booking or audit behavior changed.

The staffing summary counts distinct slots with fewer proposed interviewers than required, rather than total missing positions. Assigned interviewers who need conflict resolution are reported separately using distinct affected slot IDs, so multiple issues within one slot are not counted as multiple slots. Complete, conflict-free schedules show “All slots are staffed.” Singular/plural wording is explicit. Review slots and Review conflicts reveal the corresponding dates, switch from approved to draft view where necessary, and focus the first affected slot in deterministic chronological order without writing or dropping edits. Existing slot rows/editors retain needed-interviewer counts and detailed diagnostics. The former below-schedule warning/aggregate/list and duplicate menu revalidation entry are removed.

The standalone published-to-proposed panel was already removed by the preceding release. Its one comparison dialog remains accessible from the compact publication summary, with existing approval review and permissions preserved.
