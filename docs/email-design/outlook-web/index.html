Actual Outlook Web / Light & dark

Final SMTP design previews received by bsb4rd@virginia.edu, October 10, 2026. These screenshots are from Microsoft 365 Outlook Web in Chrome on macOS. They are recipient-side rendering evidence. They do not verify native Outlook Windows/Mac/mobile apps, Gmail, Apple Mail, or the hosted Supabase Auth publication.

All eight final previews were observed in Inbox. The official logo loaded in all 16 checks, and the organization logo loaded in all six invitation checks. Each has top and bottom captures; longer emails have an additional middle capture. Codes are illustrative and authentication links inactive. Outlook’s original Light theme was restored.
